systematix.rednoise: red noise
==============================

Residual spectra of donor fits and red-noise synthesis for S3. See :doc:`/generated`.

.. automodule:: systematix.rednoise
   :undoc-members:


Constants
---------

.. autodata:: systematix.rednoise.LC_DT

   Kepler long cadence (d).

.. autodata:: systematix.rednoise.RED_EDGES
   :no-value:

   Frequency bin edges (c/d) of the red spectra: 37 log-spaced edges from 0.01 to
   24.4 c/d (the long-cadence Nyquist frequency), each bin 1.24× wide.

.. autodata:: systematix.rednoise.WHITE_BAND

   Frequency band (c/d) over which the white-noise level is measured.
